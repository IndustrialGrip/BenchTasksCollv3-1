## Requirement applied

The template task in `tasks/examples/example-task` is the requirement: a task directory must
contain **all** of

- `docs/agent_system_prompt.md`
- `docs/task.md`
- `docs/user_system_prompt.md`
- `evaluation/main.py`
- `preprocess/main.py`
- `groundtruth_workspace/readme.txt`
- `initial_workspace/readme.txt`

On top of that the content requirements stated in the example apply: `docs/task.md`,
`docs/agent_system_prompt.md` and `docs/user_system_prompt.md` must be non-empty and written
entirely in English (no Chinese).  For the remaining files only their existence is checked.

(The root `readme.txt` of the template is not part of the contract - no task directory under any
developer branch contains one.  `task_config.json` is likewise absent from every task in this
project, including the template itself, so it is not required either.)
